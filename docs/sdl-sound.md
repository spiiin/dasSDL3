# SDL_sound

Optional `DASSDL3_WITH_SOUND=ON`, independent of ImGui/image/ttf/net/mixer.
Require `sdl3_sound` for raw APIs or `dassdl3/sdl3_sound_boost` for Result/scopes.
Pinned [SDL_sound 3.2.0](https://github.com/icculus/SDL_sound/tree/v3.2.0)
([project](https://icculus.org/SDL_sound/)), for SDL3, zlib licensed.
CMake downloads the versioned archive with SHA256 verification. No LLVM is needed
for consumers. `DASSDL3_TEST_SOUND` enables the optional parity/AOT suite.

This is an audio decoder, not a mixer or device driver. Example
[08_sound.das](../examples/libraries/08_sound.das) decodes a WAV in chunks and
queues copied PCM into an ordinary SDL playback stream. It reuses the project's
original 440 Hz `mixer-tone.wav` fixture. No additional playback abstraction.

## Raw API and metadata

All 17 header exports are generated by `tools/generate_sound_bindings.py`;
`--check` verifies the saved snapshot. Raw integer results/sentinels are unchanged.
`Sound_Sample` and `Sound_DecoderInfo` are opaque: upstream explicitly marks all
public fields read-only. 15 small adapters expose copied actual/desired specs,
flags, buffer size, decoder enumeration/strings, bounded PCM copying, a spec-ref
factory and request validation. Internal `opaque` storage is intentionally hidden.
There is no writable script view of the decode buffer.

Built-in WAV, AIFF, AU, VOC, FLAC, MP3, Vorbis, RAW, SHN and ModPlug decoders are
available in the default profile; MIDI is off. Runtime enumeration is authoritative.
Only WAV/RAW are covered by the initial PCM tests. Other codecs and Web remain
follow-ups. The embedded dr_flac/dr_mp3 symbols use private linkage; this pinned
stb_vorbis lacks a static-linkage switch, so private compile definitions prefix its
symbols. This allows SDL_sound and SDL_mixer to coexist without changing upstream
source or mixing different decoder implementations.

## Errors, decode and scopes

`Sound_GetError` has a separate consuming error channel: the next call returns
null after an error was read. `sound_error` copies it immediately into the existing
`SdlError(operation,message)`. Old errors do not turn successful calls into failures.

`decode_sound(sample, bytes)` fills a reusable owned byte array and returns
`Result<SoundDecodeState,SdlError>` with `bytes_read`, `eof`, `again`. Bytes survive
later decoding and sample destruction. A final partial chunk can accompany EOF.
Zero bytes alone do not imply EOF. EAGAIN is exposed without a retry loop inside
the binding. On a decoder error any returned partial bytes remain in the caller's
array, and the copied error is returned. A second call after a sticky error gives
an explicit error; after EOF it gives an empty successful EOF chunk without calling
raw Decode again. A native short-read fixture verifies EAGAIN; real nonblocking devices remain unverified.

Use `with_sound` once inside an outer SDL scope. SDL_sound Init is not reference
counted: a second Init fails. Quit frees every remaining sample. In this pinned
source Init calls SDL_InitSubSystem(AUDIO), while Quit does not match it with
SDL_QuitSubSystem; the outer SDL_Quit is therefore required at final shutdown.
Do not nest sessions or manually quit/free resources borrowed by a scoped block.
`with_sound_sample` frees its sample on normal and early Result return. As with
other boost scopes, arbitrary application panic is not a cleanup guarantee.

Factory requests must have a positive PCM spec and a nonzero buffer consisting of
whole output frames, at most INT_MAX bytes. Raw functions keep upstream behavior
and require valid live pointers and buffer sizes. `Sound_DecodeAll` is raw only:
it allocates an unbounded complete stream; use chunked decoding for bounded memory.
`Sound_GetDuration` returns milliseconds; -1 remains the raw unknown sentinel.

## IO and memory ownership

Raw `Sound_NewSample` retains the IO stream until FreeSample (or Quit). Ordinary
unsupported-format failure closes it too, but rejection before initialization and
allocation failure can leave it open in this pinned implementation. Consequently
there is no unconditional consuming IO Result factory. Raw callers must observe
these upstream preconditions; an allocation-failure ownership repair is pending.
`Sound_NewSampleFromMem` borrows data, even though it owns its internal IO object:
keep the original storage live and stable until sample destruction. There is no
unsafe array-to-retained-pointer convenience wrapper.

Some `Sound_SetDesiredFormat` failures set SDL_GetError without forwarding it into
Sound_GetError in this version. It remains raw; do not use `sound_error` as an
universal substitute for checking a particular API's error channel.

## Verification

Local validation targets Windows x64/MSVC.

`tests/sound.das` directly executes all 17 raw exports, checks exact PCM samples,
chunk EOF, seek/rewind, copied buffers/errors, invalid requests and early Result
cleanup. `tests/sound_native.cpp` checks actual IO closure on FreeSample and Quit,
and retained IO after pre-initialization rejection. Coverage/generation gates,
legacy/CppGenBind/interpreter/AOT and a no-LLVM consumer accompany these tests.
The native fixture also checks a short read yielding EAGAIN and S16-to-F32 conversion
against a sample oracle. Dummy audio validates queue/device operation, not physical
speaker output.

Pinned WAV decoder limitation: its source treats a zero-byte IO read as EOF and
still checks `retval == -1` for errors even though SDL3 ReadIO returns size_t.
Consequently some IO failures/truncated WAVs can look like EOF. The binding preserves
reported SDL_sound flags; it cannot promise detection of every damaged input.
