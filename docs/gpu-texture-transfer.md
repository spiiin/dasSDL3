# RGBA8 GPU texture transfers

> Current error/lifetime contract: [error-handling.md](error-handling.md).
> SDL failures return values; scopes use defer. Earlier panic/protected-scope
> descriptions below are historical and no longer describe the public binding.

Second public G3 slice, after buffer transfers. Native adapter:
`src/sdl3_gpu_texture_transfer.h`; script module:
`dassdl3/sdl3_gpu_texture_transfer_boost`; example 24.

## Contract

- `with_gpu_rgba_texture(width,height,layers,levels)` owns a checked texture ID.
  The shorter overload uses one layer and one level. Format is RGBA8 UNORM,
  sample count 1, SAMPLER usage, type 2D or 2D_ARRAY. Every mip/layer starts at
  zero, including alpha. Mips are allocated and initialized, not generated by
  filtering the base level. These IDs are separate from fixed mesh textures.
- Dimensions are 1..8192, layers 1..256, levels 1..floor(log2(max(w,h)))+1.
  Each mip dimension is max(1, base >> mip). The sum of aligned staging
  footprints across all levels/layers must be <=64 MiB. Hardware creation can
  still fail. This limit is a binding policy, not the GPU's advertised maximum.
- Subresource is `uint2(mip,layer)`, region is `uint4(x,y,width,height)` in texels.
  Zero dimensions, invalid levels/layers and out-of-bounds regions are rejected
  before allocation/recording. Bounds checks avoid overflowing x+width/y+height.
- `gpu_upload_texture` accepts a copied byte array and row pitch **in bytes**.
  Pitch must be at least width*4; odd byte pitch is supported. Required bytes
  are `(height-1)*pitch + width*4`; padding after the last row is not required.
  Extra array bytes are allowed, up to the 64 MiB input cap. Padding is ignored.
  Upload repacks into private 256-byte-aligned staging rows with offset zero;
  SDL receives pixels_per_row in pixels. Staging padding is zeroed.
- Partial uploads preserve pixels outside the region and all other subresources.
  Cycling is explicit and only allowed for a full replacement of a texture
  with one level and one layer. Failed submission invalidates the affected
  subresource until a successful full-subresource upload; a pre-submit failure
  does not invalidate existing contents. This contract is not device-loss recovery.
- `gpu_copy_texture` copies a source region to a destination origin on the same
  scoped device. Both textures must be live and distinct, with valid selected
  subresources. Same-texture copies are rejected even between distinct mips.
  No scaling, filtering, format conversion or cycling occurs.
- `with_gpu_texture_readback` submits a snapshot of the selected region and
  returns the shared readback ticket type. Existing `gpu_poll_readback`,
  `gpu_wait_readback`, `gpu_readback_bytes` apply. Output array size must be
  exactly width*height*4. It is tightly packed RGBA8, row-major, top row first;
  driver padding is never copied to script. Repeated reads are allowed.
- Source textures may be updated/released after requesting readback without
  changing the queued snapshot. SDL defers native texture release for pending
  commands. Closing a ticket invalidates its ID immediately and retires its
  fence until signaled, preserving the Vulkan fix from `gpu-transfer.md`.
- Main-thread/live-scoped-device checks and the shared monotonic ID namespace
  reject stale, foreign-device and wrong-kind IDs. All native recording is
  closed; no script callback executes inside a copy pass. Scopes use protected
  invocation and catch/cleanup/rethrow. Device cleanup releases only its own
  textures; the base device owner waits for idle before callbacks run.

## Coverage and limits

`SDL_CopyGPUTextureToTexture` and `SDL_DownloadFromGPUTexture` gain limited public
adapters. Existing creation/release/upload/format-support adapters now also have
the independent RGBA8 texture path. Readback tickets reuse the buffer fence API.
The generic native readback reader strips row padding only for texture tickets;
buffer tickets retain their unchanged contiguous-byte contract.

Not yet provided: other/compressed/depth formats, 3D/cube textures, arbitrary
usage flags, MSAA, automatic mip generation, blit, graphics/compute bindings of
these IDs or public mapped transfer views. This batch does not complete G3/P6.

`tests/gpu_texture_transfer.das` covers all initialized mips/layers of odd-sized
textures, minimal and odd source pitch, exact pixels, source-array lifetime,
cross-mip/layer region copies and unchanged neighbors, queued snapshots before
cycling/release, stale/wrong-kind/foreign-device IDs, bounds/overflow/caps,
normal/return/panic cleanup and rapid retirement of 64 readback tickets.
The new CTests fail on Vulkan VUID/Validation Error and D3D12 ERROR output.
Hardware loss and injected allocation/submission failures remain unverified.
