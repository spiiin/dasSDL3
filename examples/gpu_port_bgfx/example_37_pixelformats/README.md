# 47-pixelformats port

[Original bgfx example](https://github.com/bkaradzic/bgfx/tree/7e3060ccb97959dcda3f091b96d82515197028e0/examples/47-pixelformats). See `../LICENSE-bgfx.txt` and `../upstream/ports47-49.json`.

Four original samples: procedural hue wheel, alpha test, UV filtering test and texture-compression set. The ImGui table selects a format, preview size, checkerboard alpha compositing and animation. Selected sample updates the selected-format preview. Color-target support is queried separately from sampling support.

126 sample/format combinations are prepared offline, like bgfx's CPU-side bimg conversion. At runtime each source is uploaded in its **actual SDL GPU format**, then the DSL samples it into an RGBA preview. BC1/2/3/7 and ASTC source blocks are retained verbatim; unsupported formats are reported without attempting creation. Normalized, signed-normalized, floating-point, packed and sRGB variants are included. Integer and depth formats are excluded, following the original example. BC4/5/6H have no supplied source sample; ETC, ATC and PVRTC have no SDL GPU counterpart. There is no emulation checkbox: SDL has no equivalent bgfx emulation capability bit. The sampler is linear; previews are base-level images, as upstream.

Regressions sample every supported combination, check red/green channel packing and alpha compositing. The catalog is generated by `tools/build_bgfx_47_49_assets.py`; do not edit it by hand.

Run from the repository root (ImGui-enabled libraries runner):

```powershell
./build/ninja/bin/dasSDL3_libraries_runner.exe examples/gpu_port_bgfx/example_37_pixelformats/main.das
```

Add `--smoke-test` for a bounded launch. Verified: interpreter regression and ImGui smoke launches on Windows Vulkan/D3D12; strict AOT regression and main entry point on Vulkan (fallback disabled); deterministic DSL compilation and SPIRV-Tools validation. CMake registers the regressions. Other platforms require separate verification.
